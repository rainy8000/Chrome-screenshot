# Google chrome录屏截图工具
## 界面

![界面](https://github.com/user-attachments/assets/59e3cbb1-aaee-4105-8599-bc45c4738e86)

## 功能：

1，可实现浏览器内容整个界面截图，需要加载完成（动态页面暂时不支持）；

2，可自定义保存图片类型以及视频类型；

3，该项目支持度Macos由于Windows。


## 使用方法：

1，浏览器打开“开发者模式”

2，点击“加载已解压的扩展程序”

3，选择“该文件夹”

4，即可使用该工具
